# Changelog

## [v1.1] - {PR_MERGE_DATE}

- Launch coding agents with a prompt template (built-in or custom).
- Resume the last agent session for a project (Claude Code and Codex).
- Ask a one-shot question about the current repo and read the answer in Raycast.
- Generate a conventional commit message from the current diff and copy it to the clipboard.

- Search local projects by name, path, repository, or remote.
- Launch Claude Code, Codex, Gemini CLI, custom agents, or a terminal session.
- Open projects in Visual Studio Code, Cursor, Finder, Terminal, Ghostty, or iTerm.
